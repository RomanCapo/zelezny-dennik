# Železný denník

Osobný fitness denník ako webová aplikácia (PWA): zápis tréningov, osobné rekordy, koľko chýba do PR a databáza 873 cvikov s ukážkami.

- Funguje offline a dá sa pridať na plochu telefónu.
- Dáta sa ukladajú len v zariadení (localStorage). Zálohu stiahneš cez ikonku šípky v hlavičke.

Zdroje: cviky a fotky z [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense), písma Figtree a Big Shoulders Display (SIL Open Font License, viď `fonts/`).
